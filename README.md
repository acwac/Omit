# Omit

Omit is a lightweight ad, tracker, ISP-unblocker, and privacy shield for Android, Smart TV, and Windows 10/11. It works out of the box with zero setup and near-zero battery drain.

## Download & Update

- **Official Website:** https://acwac.github.io/Omit/
- **Android & Smart TV:** [Download Omit.apk](https://acwac.github.io/Omit/downloads/Omit.apk)
- **Windows 10 / 11:** [Download Omit-Windows.exe](https://acwac.github.io/Omit/downloads/Omit-Windows.exe)

## Features

- **Blocks ads & trackers with near-zero battery use** — keeps normal video and download traffic in the OS kernel. Optional Wi-Fi sharing is the one exception, and it is off by default.
- **Whole-Home Wi-Fi Shield** — protects TVs, consoles, and iPhones on your Wi-Fi via `:8080` / `/omit.pac` with zero apps installed on them.
- **Burner Email** — disposable `mail.tm` / `guerrillamail` inbox with 1-tap code copy.
- **Opens ISP-blocked sites at full speed** — local anti-DPI unblocking while keeping your local IP for UPI and banking.
- **Never breaks Google Play Games or sign-ins** — permanent safe list for Google, Facebook, Apple logins, and cloud saves.
- **Silent Wi-Fi Tamper Guard** — verifies upstream TLS certificates in the background and alerts only if SSL tampering is detected.
